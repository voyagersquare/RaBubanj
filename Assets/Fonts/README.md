# Wordmark font

Great Vibes Regular, The Great Vibes Pro Project Authors, under SIL Open Font License 1.1. The unmodified font is embedded for the dark-red RaBubanj wordmark, as a calligraphic interpretation of the user reference; it is not the proprietary Aventalia font shown in that reference.

- Source: https://github.com/google/fonts/tree/main/ofl/greatvibes
- File: `GreatVibes-Regular.ttf`, 457,588 bytes.
- SHA256: `8d509802186f1b51572531ecf313e8098f9a5bfdfaca93f0c9b34467f9982d15`.
- License: `OFL.txt`, also copied into portable packages as `ThirdParty/GreatVibes-OFL.txt`.

The renderer builds and caches actual glyph outlines on the GUI thread. Users do not need to install the font.
