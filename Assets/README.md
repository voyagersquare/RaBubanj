# Wood reference asset

The original user-supplied image is pending as a downloadable PNG/JPG attachment.
No replacement texture has been generated or downloaded.

Place the unchanged original at `Assets/wood-reference.png`, `.jpg`, or `.jpeg`.
CMake embeds those source bytes in the plugin; decoding is cached on the GUI thread.
Wood faces use uniform scaling and cropping, with relief lighting drawn separately.
Without the asset this work-in-progress branch renders solid-colour relief previews.
